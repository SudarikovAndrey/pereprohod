# Перепрохождение

Прототип режима «Перепрохождение» для «Рынка пацана»: пройденный район заново — захват точек
дракой, три тира прокачки с перестройкой, склады и цеха, три отправки софты и три заказа.

**Играть:** https://sudarikovandrey.github.io/pereprohod/

Прогресс и лог партии хранятся в браузере. Экспорт лога — в меню ≡ → «Экспорт» (копирует JSON
в буфер обмена). Тест-стенд с читами и прогонами бота — там же.
